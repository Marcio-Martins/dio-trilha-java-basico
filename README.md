# Trilha Java Básico

Repositório de exercícios e pequenos projetos desenvolvidos durante meus estudos de fundamentos da linguagem Java.

## Objetivo

Praticar conceitos iniciais de programação, organizar o código em classes e registrar a evolução dos estudos.

## Conteúdos presentes

- Tipos de variáveis e operadores
- Comentários e estrutura básica de programas
- Calculadora simples executada no terminal
- Simulação de operações básicas de uma Smart TV

## Tecnologias

- Java
- JDK
- Terminal e Visual Studio Code

## Como começar

1. Instale um JDK compatível com os exemplos.
2. Abra a pasta do exercício que deseja executar.
3. Compile os arquivos Java e execute a classe que contém o método `main`.

Os exemplos são independentes; consulte os arquivos de cada pasta para identificar a classe principal e os comandos específicos de execução.

## Estrutura

- `Java-Terminal/`: exercícios de terminal, incluindo uma calculadora.
- `sistema-smart-tv/`: exemplo de classes para representar uma Smart TV e sua interação.
- `tipos-variaveis/`: exemplos de tipos e operadores.

## Observação

Este repositório reúne exercícios de aprendizagem. Os exemplos serão aprimorados conforme meus estudos avançarem.
